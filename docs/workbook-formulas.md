# 工作簿公式引用基础

R3-05 实现第一方公式解析、共享模板、引用绑定和结构映射。它为 R3-06 导入和后续核心事务提供基础，**尚未实现 R3-10 求值、依赖图、自动重算或正式工作簿编辑**。解析成功不代表函数已经可计算。

## 语法与来源

单元格公式仍保存为分块 HTML 中的 `data-formula`。缓存值及状态继续与公式分开；AST、名称/表格绑定和共享模板都是派生状态。原始表达式不会因读取自动规范化。

[解析器](../packages/core/src/workbook/formula.ts)支持数值、字符串、布尔、错误、缺省参数、函数调用、标量运算、相对/绝对/混合 A1 引用、跨表引用、普通矩形、整行整列、名称、联合与交叉区域。函数参数逗号与引用联合逗号区分；括号保持引用运算优先级。前缀正负号、百分号和乘方遵循 Excel 的优先级和结合规则。

[结构化引用](../packages/core/src/workbook/structured-reference.ts)覆盖表名/省略表名、列/列区间、All/Data/Headers/Totals/This Row、Headers+Data、Data+Totals、`[@Column]` 简写和列名特殊字符转义。省略表名时需提供实际所属表，不能根据可见 DOM 猜测。绑定器按源表几何、列名和表头/汇总行计算至多一个矩形；空数据区显式表示为空，未知表/列和无效当前行返回相应公式错误。

相对引用保留为相对公式所在格的偏移；相同复制模板共享 AST。原生共享公式按工作表建立有界定义表，保存组号、来源坐标、声明范围和模板，不为每个跟随格常驻一棵树。重复基准、缺失基准、越界跟随及超预算明确失败。原生导入可先扫描共享定义，再逐块解析实际单元格。

数组常量、溢出 `#`、普通操作数前的 `@`、外部工作簿和三维跨表范围不在本轮语法内；不能可靠解释时明确失败。普通未实现函数可保留语法及来源缓存，是否可计算和缓存何时失效由后续计算层判断。不使用 `eval`、第三方公式引擎或单元格地址字符串替换。

## 引用映射

[重写器](../packages/core/src/workbook/formula-rewrite.ts)只接收表达式、旧/新位置、类型化结构变化及必要的绑定信息，不提交文档、修改历史或读取宿主数据。

| 操作 | 行为 |
| --- | --- |
| 复制 | 调整相对分量；绝对分量和字符串常量不变；越界产生 `#REF!` |
| 插入行列 | 起点之后的引用移动；范围内部插入扩大范围；`$` 不阻止结构映射 |
| 删除行列 | 相交范围收缩；完全删除的引用产生 `#REF!`；不裁成错误的包围框 |
| 剪切移动 | 单格及矩形引用跟随数据；部分移动按用户决定拆为精确多区域；跨表保留正确限定 |
| 排序 | 用户决定区域外公式保持地址；区域内公式随记录搬移并调整相对分量；批注跟随数据由后续锚点层实现 |
| 工作表改名/删除 | 映射显式与隐式作用域；删除产生 `#REF!`；字符串文字不改变 |
| 表格/列改名 | 使用名称绑定与结构化引用节点；不误改相似名字或字符串；裸表名需确认绑定，省略表名的列引用需所属表 |

剪切拆分按矩形计算，与区域实际格数无关；重叠目标去掉重复覆盖。整行整列也不展开为百万个点。新增片段及最终表达式受预算限制，超限整项失败。把当前行表格公式剪切到表外时，使用原表几何绑定具体来源行，保留数据引用；不能把目标行误当原记录。普通结构化列引用仍绑定其表。

不受影响的公式保留原始字符串，避免一次小结构编辑仅为了格式规范化而重写整本分块。需要修改时使用带括号的规范输出并重新解析校验。跨表范围一端越界时，另一端仍保留工作表限定。

这些工具尚未接入工作簿事务；实际表格、名称、坐标及作用域的完整绑定随 R3-07 模型和 R3-09 编辑边界接入。它们不授予宿主写权限，也不绕过候选整批校验。

## 预算与验证

公式源码最多 8192 UTF-16 单位，token/节点限制 4096，解析与输出深度最多 128。左结合长链也检查实际 AST 深度。工作簿模板和原生共享组各有累计预算；来源失败不留下半个模板。数字标量的词法与整行引用区分，不能把 `1e0:3` 悄悄改成 `1:3`。

93 个针对性测试覆盖分块/模型、解析、输出、共享组、表格绑定和引用映射；其中原生来源检查处理 16 个独立源及其 Calc 重存的四万余个公式/引用表达式，包括一万行样例、共享公式、表计算列、验证、图表及打印名称。独立点映射检查剪切重叠与删除边界，不只比较重写器自己的中间结构。类型和包依赖边界检查通过。测试不宣称计算结果或 SDK 原生导入已通过。
