# PPT 对象编辑与输入

R2-08 至 R2-13 提供第一方幻灯片／对象、文字／表格／备注、定义、基础图表和两类批注编辑器，以及请求／提案工作台，复用固定画布和 [PPT 事务](presentation-transactions.md)。交付状态及验证记录见[第二轮细则](iteration-2.md)；协作入口见 [PPT 工作台](presentation-workbench.md)。

```ts
import { createDocumentSession, openDocument } from "@dagent-office/core";
import { mountPresentationEditor } from "@dagent-office/editor";

const session = createDocumentSession(openDocument(files));
const view = mountPresentationEditor(container, session, {
  onSelectionChange: selection => hostSelectionChanged(selection),
  onError: error => hostShowError(error),
});
await view.ready;
view.setZoom(0.75);
view.dispose(); // 宿主仍拥有 session 和保存行为。
```

`@dagent-office/editor/react` 还提供 `PresentationEditor`，接受宿主会话、相同选项和 `onViewChange`。普通 JavaScript 使用不依赖 React。普通 JS 的 `mountDocumentWorkbench` 以 `{format:"presentation"}` 选择 PPT 适配器；也可直接使用 `mountPresentationWorkbench`。React 使用 `PresentationWorkbench`。Word 默认入口及 Word 协议保持原契约。

## 幻灯片与对象

导航按 HTML 源顺序显示幻灯片，元数据数组只是身份登记。可新增指定既有布局的页面、复制、换序、隐藏和改名；至少保留一页。新增布局页复制并重新登记占位符，保留其继承引用。复制页面保留备注、局部对象、内部连接及链接；图表获得独立数据集，图片复用不可变字节。审阅线程继续属于原页面，复制内容不复制审阅讨论。

对象工具支持文本框、声明的形状、图片、直线／折线和表格创建；图表可创建、复制并编辑常量数据。核心分配所有新节点、图表和数据身份，重写内部引用。删除完整页面同时删除其备注和对象，并保留失效批注的富文本恢复内容；到已删除页面的跳转解除。新图片通过 `view.insertImage(authorizedBytes, mimeType, alt?)` 或本地文件选择进入同一资源事务，没有 URL 获取或隐式上传。

对象选择和几何编辑支持：

- 单选、Shift 多选、对象导航、上层组合选择，以及同层对象的复制、层级、对齐和等间距分布。
- pt 坐标和尺寸、旋转、水平／垂直翻转、矩形图片裁剪，以及 16 种预设切换。
- 实色、线性渐变、不透明度、轮廓、虚线和基础外阴影。调整已有渐变的角度、不透明度或末端颜色会保留其他停止点；选择新的渐变样式创建两端渐变。
- 连接对象、原生连接位置和直线／折线类型修改；绑定源缓存和间接影响仍在同一次事务中更新。解绑保留缓存几何，无效位置使整批失败。
- Delete 删除、方向键移动、Shift 方向键移动 10 pt、Ctrl/Command+D 复制、Ctrl/Command+G 组合、Shift+Ctrl/Command+G 取消组合，以及统一撤销重做。

`view.perform(operations, prepareOptions?)` 经过会话准备和提交，失败候选会丢弃。宿主可以独立调用这些核心类型化操作，编辑器没有独立推进的状态模型。`selection()` 返回当前修订的对象锚点；来源身份和本地文件名只用于关联及展示。

## 手势和组合

拖动、右下角缩放及旋转手势绘制临时轮廓，结束后提交一次。Escape、pointercancel、丢失指针捕获或来源修订变化取消手势，源和历史不变。测量采用渲染后的父坐标矩阵，覆盖缩放、嵌套组、旋转和翻转；采用 750 pt 对应 1000 CSS px 的探针，避免 1 pt 探针的布局取整误差。探针同步移除，选择手柄位于源根以外。

组合保留对象身份和所选对象的相对顺序，组合位于原选择的最上层位置。取消组合组合原生变换，并保留字体的字形方向和来源字号；斜切、奇异变换、不能保持原生路径／文字矩形或外观的情况明确拒绝。当前直接组合不接受原生占位符；带样式的组、影响组祖先关系的源选择器，以及缩放后需要重新表达的描边、阴影或特殊对象外观需要保留组合，不进行近似。独立 PPTX 中可表示的旋转／翻转组有核心精确坐标和浏览器显示验收。

## 文字、表格与备注

`view.editText(nodeId?)` 在真实文本框、形状或表格源上绑定第一方 beforeinput、DOM Range 和组合输入；`view.editNotes(slideId?)` 编辑已有备注实例，或在首次输入时原子创建备注故事。工具栏提供字符、东亚／西文字体角色、段落、列表、自适应和换行模式；表格提供行列增删、行列尺寸、矩形合并／拆分、有界 TSV 粘贴，以及按网格选区设置单元格填充、边框和水平／垂直对齐。跨单元格文字删除保留表格网格。剪贴板保留源格式，定位对象及不支持的富文本内容明确失败。输入、格式及结构编辑使用同一核心历史；IME 期间外部修改会拒绝迟到输入，并可通过 `onInputRecovery` 返回未应用片段。取消输入不提交空段落。

## 定义与图表

`view.setDefinitionSurface(rootNodeId?)` 切换到真实母版、布局或备注母版画布。定义工具支持创建、复制、引用、背景、布局名称和删除替代；主题颜色／字体及定义修改先显示候选影响页面，再统一应用或放弃。新建页面的文本占位符保留继承，局部覆盖可显式恢复。布局切换保留已有文字；无法在新布局找到几何来源时保留原几何。全局定义的候选及直接画布编辑仍经过相同事务。主题颜色编辑修改原生调色板槽，并保留母版颜色映射。主题提供标题／正文的西文、东亚和复杂文字字体；DrawingML 的一个西文字体槽对应源模型成对的 ASCII/HANSI 角色，编辑主题时保持二者一致。已有备注可以选择或解除备注母版引用。

图表工具以 HTML 输入表编辑分类、系列、常量数值和空值，支持柱形／折线／饼图、标题、图例、标签、基础轴范围和系列颜色。新增系列由核心分配身份；复制图表的数据相互独立，编辑共享样式时为该图表隔离样式。无内嵌工作簿缓存参与编辑；PPTX 工作簿由 R2-14 从当前常量生成。

## 批注与区域

经典／现代批注支持新增、富文本正文、回复、状态、作者日期、定位与重新锚定、删除和统一历史。现代回复拥有独立源节点；删除线程清理其正文与回复。失去锚点保留恢复内容，撤销恢复原锚点和状态。作者名称仅供显示。

`view.selectRegion(slideId, rect)` 使用幻灯片内部 pt 坐标。按页布局指纹排除页面排序、页名和备注对画布的影响；相关几何、定义和字体变化使测量区域需要重定位。工作台还检查当前渲染字体环境。原生经典批注的固定页内位置不依赖字体测量；页被删除时仍保留恢复位置。

## 验证与边界

核心与原生样例测试覆盖源顺序、最后一页、复制图表隔离与资源复用、备注、删除恢复、原子失败、无变化、形状调整值保留、组合及斜切拒绝。浏览器覆盖编排、两个缩放比例的手势、取消与并发修改、键盘、缩放旋转、原生组显示、图片／裁剪／撤销、渐变停止点和连接端点。CI 将完整 PPT 编辑及工作台场景纳入 Chromium、Firefox、WebKit 和 Chromium 109，并在 macOS Safari 验证原生输入、提案、历史和释放；最终通过结果以交付 PR 的当前提交为准。Word 回归继续保留。

HTML 包可保存重开。原生 PPTX 导出和外部编辑重开仍归 R2-14 至 R2-16，当前对象操作通过不代表已完成这些导出验收。
