## 来源和检查边界

[独立样例](../examples/xlsx/README.md)由 Python ZIP/XML 生成，保留独立预期、摘要、固定字体 PDF/PNG 和实际 LibreOffice 25.8.1.1 重存。16 份原始文件及其 16 份实际生产者文件分别做公开导入、完整包保存重开和公共预览；不把 Calc 重存作为原源的替身。

`tests/browser/workbook-preview.spec.ts` 对全部 32 份文件在现代三引擎和固定旧 Chromium 上验证每张可见表的首／末窗口、报告、可见导航、包不变、无整本序列化、资源释放，并保存截图和 JSON。`scripts/collect-workbook-reading-matrix.mjs --record` 只汇总与当前公共宿主包摘要一致的 128 份完整结果。包按 Base64 传给测试浏览器，避免将每个字节包装成 Playwright 协议对象；该测试传输不改变 SDK 字节接口或容量门槛。

更细的几何、实际像素、UTF-16、输入安全、累计预算、失败候选、取消／迟到及 Worker 所有权由 `workbook-grid`、`workbook-drawing`、`workbook-drawing-window`、`workbook-preview`、`workbook-read-worker` 和 `workbook-playground` 套件覆盖。结构、公式及样式的单元检查覆盖对应原生来源、17 类非法源和保存重开。

## 独立原生结论与差异

规范依据、固定 Calc 观察和 SDK 选择分别记录在[工作簿模型](workbook-model.md)及 `docs/evidence/xlsx-*.json`。主 32 份文件通过官方 Transitional XSD／关系审计。额外标签探针的 4 个实际 Calc 图表存在 numFmt／dLbl 子元素顺序错误；原文件保留，独立验证断言这些错误，只在验证副本检查其余结构，绝不计为 XSD 合规。

Calc 会扁平化现代线程、将财务下划线改成普通下划线、丢弃某些图片／渐变开关、改写负柱反转和标签设置；这些损失保留在生产者输入及观察中，SDK 不从原源偷偷恢复。用户已选的整格财务下划线、隐藏列自动行高、VML 优先、忽略旧折线总开关、Office 轴语义、刚性旋转渐变和白色负柱都作为独立要求验证。SDK 网格与原生打印页的分页／缩放／自动布局不要求像素一致；人工查看基础日期／表格／图表／绘图截图，并结合固定字体下的定向文字边界和颜色采样。Excel/WPS 未实机核验。
