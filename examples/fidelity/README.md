# 样式与资源保留样例

本包用于验证 R1-05 的资源完整性及保存重开，覆盖中文字体声明、行内格式、Unicode、段落、列表编号、合并表格、三种图片和页面设置。图片是本项目用浏览器 Canvas 生成的 8×8 色块，不来自用户文档。

该包继续作为核心边界夹具；DOCX 读取与后续交互须另用实际格式样例验收，见[第一轮细则](../../docs/iteration-1.md)。

当前验证 HTML/CSS 规范化后的语义及资源原字节往返，不代表已完成浏览器视觉、编辑或 Office 导入导出验收。字体只保留名称和回退列表，未嵌入字体文件；固定字体、分页及截图对照在渲染阶段加入。能力边界见[资源与 ZIP](../../docs/resources-and-zip.md)。
